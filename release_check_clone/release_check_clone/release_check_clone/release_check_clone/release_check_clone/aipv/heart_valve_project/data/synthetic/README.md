Dataset README

This folder contains synthetic datasets generated by the ValveBench pipeline.

Files produced (versioned and canonical):

- `synthetic_patient_data_v0.1.csv` / `synthetic_patient_data.csv` — patient table with columns:
  Patient_ID, Sex, Age_yrs, Height_cm, Weight_kg, BMI, BSA_m2, Valve_t0, Valve_t12, AgeMonths, AgeMonths_t12

- `synthetic_scaffold_data_v0.1.csv` / `synthetic_scaffold_data.csv` — scaffold/simulation table with columns:
  Patient_ID, Suture_Count, Material_Stiffness, Dissolution_Rate, Fold_Angle, SimValve_t0, SimValve_t12

- `synthetic_merged_data_v0.1.csv` / `synthetic_merged_data.csv` — merged patient + scaffold table

- `splits/train.csv`, `splits/test.csv` — group-preserving train/test splits (GroupShuffleSplit by `Patient_ID`)

How to regenerate dataset (from repository root):

```bash
py -3 -c "import sys; sys.path.insert(0,'aipv'); from heart_valve_project.utils.synthetic_dataset_generator import generate_and_export_pipeline; generate_and_export_pipeline(n_patients=500, seed=42, output_dir='aipv/heart_valve_project/data/synthetic/', verbose=True)"
```

How to recreate splits:

```bash
py -3 -c "import sys; sys.path.insert(0,'aipv/heart_valve_project'); import pandas as pd; from valvebench.datasets.splits import create_group_splits; df=pd.read_csv('aipv/heart_valve_project/data/synthetic/synthetic_patient_data_v0.1.csv'); train,test=create_group_splits(df, group_col='Patient_ID', test_size=0.2, random_state=42); import os; os.makedirs('aipv/heart_valve_project/data/synthetic/splits', exist_ok=True); train.to_csv('aipv/heart_valve_project/data/synthetic/splits/train.csv', index=False); test.to_csv('aipv/heart_valve_project/data/synthetic/splits/test.csv', index=False)"
```

Notes:
- The code lazy-imports `torch` in model modules; you only need `torch` if you plan to train models locally.
- Dataset versioning is applied via `DATASET_VERSION` in the generator (`v0.1`). Update before regenerating if you change generation assumptions.
