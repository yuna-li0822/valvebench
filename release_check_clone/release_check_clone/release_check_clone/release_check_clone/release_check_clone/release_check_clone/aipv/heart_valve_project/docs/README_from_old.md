Valve Project

Reorganized project for valve modeling and experiments.

Structure:

- `data/` - datasets (raw and synthetic)
- `models/` - model implementations and wrappers
- `experiments/` - training and experiment scripts
- `evaluation/` - metrics and evaluation helpers
- `notebooks/` - exploratory notebooks
- `utils/` - utility scripts (data generation, helpers)

This is a refactor of the original project into a clearer layout.
