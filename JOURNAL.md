- 2026-08-22 (session 3) — Full scientific-rigor audit per user's explicit request ("treat this as a serious research-codebase completion and validation phase, do not fabricate results"). Found and fixed real bugs; one headline claim from session 2 did NOT survive and is now reported as a negative result.
- Notes:
  - **Found: PINNVALVE's tuning leaked into its test set.** `physics_weight` had been selected by directly observing OOD RMSE on the exact dataset later used to report results, and "ID RMSE" was computed by predicting on the training set itself. Fixed with a genuinely held-out ID split (`interior_train_val_test_split_sma`, grouped by `sample_id`) and a validation OOD set (`ood_shell_dataset`) disjoint from the final `ood_corner_dataset_sma` test set. Re-swept `physics_weight` honestly: the "13% OOD improvement, robust across seeds" claim from session 2 **did not survive** — under the corrected methodology it's noise-level (-1.1% ± 4.2%, 1/5 seeds positive) at the new default weight, and actively negative at the old default (10.0: -17.2% ± 11.1%). The martensite-fraction (xi) recovery claim (never-supervised latent state, ~60% RMSE improvement) **did survive**, unchanged, at every weight from 0.1-20 tested. This is now the honestly-reported headline result instead.
  - **Found: patient-growth generator had two physiological-implausibility bugs.** `Valve_t0` was drawn independently of every feature (correlation ~0.02-0.07, noise-level), so roughly half the two-column benchmark target was unlearnable regardless of model capacity; `Height_cm`/`Weight_kg` were independent of `Age_yrs` (a synthetic 1-year-old could get height=180cm). Confirmed via direct correlation checks and a quick holdout-R² sanity fit before touching any code. Fixed: `Valve_t0` now scales with sqrt(BSA) (matching real pediatric annulus Z-score methodology's qualitative basis); height/weight now scale linearly with age (reusing the model already present in the legacy generator rather than inventing a new one). Leaderboard R² went from ~0.01 (linear/ridge) and negative (mlp/gbm/pinn) to ~0.70-0.71 across the board as a direct, measured result.
  - **Found: `MLPRegressor` had no feature scaling**, catastrophic once the generator fix gave the benchmark real signal to overfit/underconverge on (R² ~ -7.3, worse than predicting the mean). Fixed with train-only standardization of X and y plus raising max_iter 500->2000 (500 was empirically insufficient once there was real signal to converge on). `mlp` now matches `linear`/`ridge` (R² 0.71). Also fixed `Ridge`'s missing standardization (regularization strength was scale-dependent on raw, arbitrarily-scaled features).
  - Built genuine OOD evaluation for the patient-growth task (didn't exist before this session — only the scaffold-PINN task had one): age-extrapolation split (train on 3-13yo, test on excluded extremes), wired into a rebuilt `generate_leaderboard.py` that now runs 5 seeds and reports mean+/-SD with RMSE/MAE/R2, ID and OOD, instead of a single-split MAE/MSE table.
  - Added `valvebench/evaluation/metrics.py::rmse/r2`, `valvebench/evaluation/plots.py` (predicted-vs-actual, residuals, ID-vs-OOD bars, physics-weight sweep, training curves, data-efficiency -- zero plots existed anywhere in this repo before this session), `experiments/generate_figures.py` producing all 6 from real trained models.
  - New experiments, both revealing a coherent, honest story about *where* the physics prior actually helps: data-efficiency sweep (physics_weight=1 beats physics_weight=0 by up to 24% OOD RMSE at 6 training designs, fading to noise by ~24+ designs) and noise-robustness sweep (5% improvement at low observation noise, monotonically increasing to 45% at high noise). Both suggestive rather than tightly bounded (3 seeds/condition) but the noise trend in particular is a clean monotonic pattern across 5 well-separated noise levels.
  - Added `tests/test_leakage.py` (9 dedicated regression tests: patient-level, scaffold-design-level, age-range, and normalization-statistics leakage) and `tests/test_metrics.py`, `tests/test_pinn_robustness_experiments.py`. Full suite: run and passing (count grew again this session; see test directory for current total).
  - Rewrote README.md (14-point structure: what's implemented vs not, explicit "what changed on the second audit pass" section owning the corrected claim), METHODS.md, RESULTS.md (full before/after accounting for every bug found) from scratch this session -- old versions described the pre-audit, partially-incorrect state.
