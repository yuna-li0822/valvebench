# COMSOL Scaffold Leaderboard

Task: predict scaffold diameter (mm) from design (suture count, dissolution rate, crimp depth, austenite finish temperature) and time, on COMSOL finite-element data (`data/comsol/comsol_dataset.csv`, dataset comsol-v1). Unlike `scaffold_leaderboard.md`, no model's loss contains the equations that produced the targets.

Designs: {'test': 24, 'val': 24, 'train': 72, 'ood': 16}. Seeds [0, 1, 2, 3, 4], mean ± SD. ID = held-out interior designs; OOD = the 16 corners of the design box. ξ = martensite fraction, never supervised, scored against COMSOL's volume average.
